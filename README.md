
## About Me

During this period, I developed a strong understanding of C# and various design patterns. As I moved forward with developing server-based games, I began exploring the fundamentals of web technologies and backend services.

Eventually, I shifted my focus to ASP.NET and transitioned my tech stack toward web development. Building web applications opened up a whole new world for me and made my development journey even more exciting and enriching.
